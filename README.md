# Nova Distribution — Vitrine 10/10 + Landing Kitchart

## Positionnement public
Nova Distribution est présenté comme une société de distribution/sélection de produits de cuisine et de maison.
Kitchart est le premier produit phare et est présenté comme distribué officiellement par Nova Distribution.

## Parcours commercial
Accueil Nova → Catalogue → Kitchart → Landing produit → WhatsApp.
La page est volontairement conçue pour ajouter d'autres produits sans refaire l'identité du site.

## Informations volontairement NON publiées
Les tarifs d'achat, marges, paliers grossistes, conditions de partenariat, exclusivité verbale et autres informations commerciales internes ne sont pas exposés sur le site public.

## Déploiement GitHub Pages
1. Upload du contenu de ce dossier à la racine du repository.
2. GitHub → Settings → Pages.
3. Source : Deploy from a branch.
4. Branch : `main`.
5. Folder : `/ (root)`.
